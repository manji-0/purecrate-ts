# IR

日付: 2026-09-27
実装: `crates/ir`（依存なし。I/O なし）

解析も印刷も、このクレートの所有値だけを入出力にする。

## 形

- `Ty` / `Item` / `Expr` / `Pattern` はすべて enum
- 名前は平坦化済みの `Name`
- 公開面は `Vis::Pub`。到達した非公開は `Vis::Internal`
- `Fn.owner = Some(State)` なら Companion `State` の関数プロパティ
- ファイル分割は `Item::file_stem`（kebab-case）

`Result` / `Option` / `Vec` は `Ty` の組み込み構成子。ユーザー ADT は `Item::Enum` / `Item::Struct`。

## カウンタ

`purecrate_ir::counter_example()` が v0 の正規 IR。印刷器はこの値から `event.ts` / `state.ts` / `step.ts` を出す。
