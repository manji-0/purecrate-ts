# IR

Date: 2026-09-27
Implementation: `crates/ir` (no dependencies, no I/O)

Both analysis and printing take and produce only values owned by this crate.

## Shape

- `Ty` / `Item` / `Expr` / `Pattern` are all enums
- Names are already-flattened `Name`s
- The public surface is `Vis::Pub`. Reached non-public items are `Vis::Internal`
- `Fn.owner = Some(State)` means a function property of the Companion `State`
- File splitting uses `Item::file_stem` (kebab-case)

`Result` / `Option` / `Vec` are built-in constructors of `Ty`. User ADTs are `Item::Enum` / `Item::Struct`.

## Counter

`purecrate_ir::counter_example()` is the canonical v0 IR. The printer emits `event.ts` / `state.ts` / `step.ts` from this value.
